```text
Create a clean, modern, beginner-friendly responsive website called “TrimFinder” for discovering barbing salons near the user in Nigeria.

Use ONLY HTML, CSS, and vanilla JavaScript. Keep the code simple, well organized, and easy for a beginner to understand.

CORE PURPOSE:
Users should be able to find nearby barbing salons, search by location/name, compare ratings and haircut prices, filter results, and view salon details.

DESIGN:
- Mobile-first and fully responsive
- Modern Nigerian startup aesthetic
- Clean white/light-gray background
- Green as the primary color
- Black/dark-gray typography
- Gold/yellow stars for ratings
- Rounded cards and buttons
- Subtle shadows
- Large, readable typography
- Friendly icons using Font Awesome or simple emoji/icons
- Smooth hover and click animations
- Professional but simple UI

HOMEPAGE:
1. Header:
   - TrimFinder logo with scissors/barber icon
   - Navigation: Home, Explore, Favorites, Profile
2. Hero section:
   - Heading: “Find a great barber near you”
   - Subtitle: “Discover trusted barbing salons, compare prices and ratings.”
   - Search bar: “Search barber or area...”
   - “Use My Location” button with location-pin icon
3. Filter section:
   - Rating filter
   - Price filter
   - Distance filter
   - Sort by: Recommended, Rating, Price, Distance
4. “Nearby Barbers” section with salon cards.

BARBER CARDS:
Each card should contain:
- Salon image
- Salon name
- ⭐ Rating
- Number of reviews
- Location
- Distance
- “Haircut from ₦X”
- Service chips such as Low Cut, Fade, Beard Trim
- Favorite/heart button
- “View Salon” button

Use realistic Nigerian sample data such as:
- Ikeja
- Lekki
- Yaba
- Surulere
- Gbagada
- Opebi
- Victoria Island
- Egbeda
- Ikoyi

Include sample prices in Nigerian Naira, for example:
- Low Cut: ₦3,000
- Fade: ₦4,000
- Hair + Beard: ₦5,000
- Beard Trim: ₦2,000
- Kids Cut: ₦2,500

SEARCH AND FILTERING:
Use vanilla JavaScript to make the website interactive.
- Search salons by name or location
- Filter by rating
- Filter by price range
- Sort by rating, price, and distance
- Update the displayed cards dynamically without refreshing the page
- Show a friendly “No salons found” empty state when there are no matches

SALON DETAILS:
When “View Salon” is clicked, display a detailed salon view/modal containing:
- Large salon image
- Name
- Rating and reviews
- Location
- Opening hours
- Distance
- About section
- Full list of haircut services and prices
- “Get Directions” button
- “Call Salon” button
- “WhatsApp” button
- “Save Salon” button

LOCATION FEATURE:
Add a “Use My Location” button using the browser Geolocation API.
For this beginner version, obtain the user's latitude and longitude and display a message showing that the location was detected.
Structure the JavaScript so real distance calculations or a map API can easily be added later.

INTERACTIVE FEATURES:
- Favorite heart buttons
- Search
- Filters
- Sorting
- Salon details modal
- Location detection
- Mobile navigation menu
- Buttons with hover/active states
- Smooth transitions
- Loading state while salon results are being displayed

RESPONSIVE DESIGN:
Mobile:
- One-column salon cards
- Bottom navigation bar
- Large touch-friendly buttons

Tablet:
- Two-column salon grid

Desktop:
- Three-column salon grid
- Wider centered content
- Desktop navigation
- Optional map panel beside the salon listings

FOOTER:
Include:
- TrimFinder logo
- About
- Contact
- Privacy
- Terms
- Social media icons
- “Made for Nigeria 🇳🇬”

CODE STRUCTURE:
Provide the complete project as:
- index.html
- style.css
- script.js

Keep the code beginner-friendly with comments explaining important sections. Do not use React, Vue, Bootstrap, Tailwind, or any backend framework.

Make the final result visually polished and realistic, while keeping the implementation simple enough for someone learning HTML, CSS, and JavaScript to understand and modify.
```
